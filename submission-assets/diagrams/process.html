OpsMind · how an investigation flows

From daily records to a human decision

The app calculates every number; the model only explains the supplied evidence.

1

Daily records

Production, electricity, operating hours, tariff and weather context for each day.

→
2

Deterministic engine

Intensity = kWh / unit. Trailing baseline, deviation, threshold and cost formula.

→
3

Evidence context

Thirteen evidence items (E1–E13), explicit limitations and missing inputs.

→
4

Gemini explanation

Facts, hypotheses with missing evidence, and human checks. JSON validated server-side.

→
5

Human action

Open → in progress → completed. Before/after observed change with a causation caveat.

If the model fails or returns invalid output, the investigation is stored as FAILED — no substitute answer is invented.
